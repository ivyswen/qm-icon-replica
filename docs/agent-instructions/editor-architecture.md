# 编辑器与状态架构规则

适用范围：修改画布渲染、设计状态流、图层特效、蒙版或编辑器交互时。

## 核心规则

1. **单一状态模型**：所有编辑操作均通过 `ExportDesignState` 统一序列化，中央 1024px 画布（`AppMark.tsx`）、7 大平台预览（`PlatformPreview.tsx`）与导出引擎（`export.ts`）必须严格消费同一状态，禁止在各端各自维护独立样式。
2. **状态快照与历史**：每次涉及图标更换、颜色调整等关键操作，必须在修改前调用 `saveState()` 保存撤销栈，支持 Undo/Redo 与存入浏览器历史。
3. **存储容灾**：访问 `window.localStorage` 读写历史快照或主题配置时，必须使用 try-catch 包裹，并提供存储不可用时的降级提示。
