# 图标素材与检索体系

适用范围：新增离线内置矢量图形、扩充中文语义别名或调整 Iconify 在线检索时。

## 核心规则

1. **双轨检索体系**：优先在 `features/icons/data/builtinIcons.ts` 中维护 64+ 离线核心矢量图形（24×24 viewBox），保证断网或首屏零延迟；在线检索通过 Iconify API 覆盖 20,000+ 开源图标。
2. **中文语义映射**：新增中文搜索关键词时，在 `ICON_QUERY_ALIASES` 字典中扩充对应的英文检索词，支持候选词别名自动展开。
3. **矢量保真解析**：远程拉取或内置的 SVG 必须提取其实际 `viewBox` 与内部节点，避免位图化，保持高质量缩放与换色能力。
